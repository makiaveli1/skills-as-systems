# Changelog

## Collection 1.2.0 — 2026-08-15

- SITECRAFT 0.4.0 and FOUNDRY 0.3.0 now remain active across the full work
  lifecycle, with targeted re-entry when requirements, evidence, state,
  failures, ownership, environment, capabilities, or handoffs change and before
  completion.
- Added compact lifecycle references and regression cases so hosts reopen only
  the affected route or engineering mode instead of treating a skill as a
  one-time opening prompt.
- Replaced the original SITECRAFT showcase with the deeper CAIRN study: two runs
  per condition, three changing stages, deterministic browser acceptance, and
  blind visual review.
- Published the mixed CAIRN result without inflating it: all candidates passed
  functional checks; SITECRAFT averaged 22/25 versus 18.5/25, but the paired
  results split and do not prove a repeatable output advantage.
- Published the deeper FOUNDRY scenario and evaluator as work in progress. Its
  interrupted pilot is excluded and no result is claimed before clean reruns.
- Bumped the Claude Code collection plugin to 1.2.0.

## Collection 1.1.0 — 2026-08-15

- Added reproducible, paired Codex benchmark showcases for SITECRAFT and FOUNDRY with frozen prompts, seeds, rubrics, independent checks, browser evidence, mutation tests, and honest parity results.
- SITECRAFT 0.3.1 adds an explicit artifact-depth threshold so bounded single-surface work uses a compact contract instead of producing schema-shaped paperwork without a durability need.
- FOUNDRY 0.2.1 strengthens packaging repairs: permanent regressions now need to build, inspect, install, and exercise the incident-relevant artifact contract without source-tree leakage.
- Added final projects and evidence receipts suitable for independent reruns; private reasoning transcripts and installed skill copies remain excluded.
- Bumped the Claude Code collection plugin to 1.1.0.

## Collection 1.0.0 — 2026-08-15

Initial open-source release of the Skills as Systems collection with two independently installable skills.

### SITECRAFT 0.3.0

- Reduced the canonical portable package from approximately 471 MB of mixed runtime and development material to under 1 MB of skill resources.
- Removed browser profiles, generated forward-test sites, captures, logs, showcases, and active provider adapters from the canonical package.
- Front-loaded Codex and Claude activation language and made multi-route paging explicit.
- Preserved Experience Contract, Review, Handoff, generated-media, capability, evidence, portability, and optional PC Bridge systems.
- Added a regression that provider adapters and active Codex MCP configuration are not bundled in the portable core.

### FOUNDRY 0.2.0

- Prepared the first public portable release.
- Improved activation language for substantial software-engineering tasks across repositories, systems, incidents, data, concurrency, security, performance, and AI/agent work.
- Preserved progressive understanding, Change Contract, specialist routing, failure tests, verification receipts, continuity, and optional PC Bridge integration.

### Collection architecture

- Added an Apache-2.0 public repository and detailed architecture documentation.
- Added Codex project-discovery links and a safe cross-platform installer.
- Added a validated Claude Code marketplace/plugin wrapper without duplicating the canonical skills.
- Added repository hygiene, Agent Skills, host metadata, package-size, link, version, privacy, secret, and clean-install validation.
- Added cross-skill activation fixtures and a release evidence model.
