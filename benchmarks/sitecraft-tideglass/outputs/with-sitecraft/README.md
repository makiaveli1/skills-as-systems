# TIDEGLASS departure board

A responsive, single-page harbour departure briefing built with plain HTML, CSS, and JavaScript. All data and form behaviour are fictional and local to the page.

## Run locally

Open `index.html` directly in a modern browser. No install, build step, server, or network connection is required.

## Interaction

- Select **Now**, **07:00**, or **09:00** to update the decision and observations.
- With keyboard focus on a time band, use the arrow keys, Home, or End to change selection.
- The notice form validates locally and simulates submitting without transmitting or retaining an address.
- Enter `fail@demo.test` to exercise the local failure state.

## Trust boundary

This is a demonstration interface, not a navigation service. It contains no live feeds, integrations, storage, or external dependencies.
